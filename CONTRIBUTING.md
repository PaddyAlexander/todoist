# Contributing

Contributions are welcome. Accessibility improvements are especially appreciated.

## Setup

1. Install dependencies: `yarn install`
2. Copy `src/firebase.js.example` to `src/firebase.js` and fill in your own Firebase config.
3. Start the app: `yarn start`

## Running the tests

- `yarn test` runs the tests in watch mode.
- `npx react-scripts test --watchAll=false` runs them once.

Tests live in `src/__tests__/`. Please add or update tests for any change you make.

## Code style

The project uses ESLint (Airbnb config) and Prettier. Please make sure your code passes both before opening a pull request.

## Pull requests

- Keep each pull request focused on one change.
- Describe what you changed and why.
